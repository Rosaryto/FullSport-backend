# FullSport · Backend

Backend del e-commerce FullSport (proyecto final de RollingCode).

## Tecnologías
- Node.js
- Express
- MongoDB Atlas y Mongoose
- pnpm

## Instalación
1. Clonar el repositorio.
2. Ejecutar `pnpm install`.
3. Crear un archivo `.env` con las variables de `.env.example`.
4. Ejecutar `pnpm run dev`.

## Endpoints
| Método | Ruta | Descripción |
|---|---|---|
| GET | /api/prueba | Comprueba que el backend funciona |
